# SANE Knowledge Assistant — Delivery

Present the skills changed, the workstream evidence and current repository facts
supporting each change, and the checks performed. Identify findings left outside
skill scope or not established by available evidence. If no skill needed updating,
explain why. Discuss follow-up changes with the user within the agreed scope.
