# C10 — Human verification and foundation acceptance

Owner-approved scope: human verification after automated verification
passes. This checkpoint owns usability and the realistic full-workstream acceptance
journey, not another round of manually manufactured concurrency/crash tests.

## Human journeys

| Journey | Owner verification |
| --- | --- |
| Fresh setup | Follow the supported installation/configuration/startup flow without manual repairs; instructions and failure messages are understandable. |
| Multi-project navigation | Switch repositories, linked checkouts and conversations; the displayed workstream, context and execution checkout are clear. |
| Native ↔ App continuity | Continue and attach conversations through terminal and App; history, context, ownership acknowledgments and recovery messages make sense. |
| Desktop/mobile input and history | On actual devices, verify repeated spaces, autocorrect, accents/IME, first-line edits in long drafts, selection/copy, retained drafts when switching, Send and desktop Ctrl/Cmd+Enter. Browse old history during output/sibling updates, expand tool details and use Scroll to latest. |
| Full workstream, last | Complete Design → Engineering → Planning → Execution with explicit approvals, amendments where needed, jobs/reports and supporting Research. Recipients perform real pickup, report readiness and accept user continuation; existing-session replies work naturally. |

Ordinary messaging, caller linking/context, all four handoff directions, existing-session
reply and correlated completion have already passed owner verification. Do not repeat
marker prompts without a relevant change or regression. Automated verification supplies
technical evidence for idempotency, target ambiguity, scheduling, cancellation, crash
timing and recovery.

## Completion

Resolve essential defects found in these journeys with focused re-verification. Keep
remaining limitations explicit. Full foundation acceptance requires both automated
technical evidence and owner acceptance of C10. Broader UX refinement remains separately
scoped; this checkpoint does not authorize a redesign or expand foundation exclusions.
